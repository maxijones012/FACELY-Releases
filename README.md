# FACELY Releases

Repositorio público de distribución de **FACELY**.

Este repositorio contiene únicamente archivos de actualización y versiones compiladas. El código fuente principal de FACELY se mantiene separado.

## Actualizaciones

FACELY consulta `latest.json` para detectar nuevas versiones. Los APK oficiales se publican mediante GitHub Releases y se verifican mediante SHA-256 antes de instalarse.

> Las actualizaciones deben conservar el package `ar.com.rostrolocal` y la misma firma de la aplicación para instalarse encima sin borrar los datos locales.
